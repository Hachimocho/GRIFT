# Core Components

The core components form the foundation of the HyperGraph framework. These include the graph data structure, nodes, and edges.

## Components

- **[HyperGraph](HyperGraph.md)** - Core graph data structure
- **[Nodes](Nodes.md)** - Node classes representing data points
- **[Edges](Edges.md)** - Edge classes connecting nodes

## Overview

The core components provide the fundamental data structures for representing data as graphs:

- **HyperGraph**: Container for nodes and edges, provides graph operations
- **Nodes**: Represent individual data points with attributes, labels, and metadata
- **Edges**: Connect nodes based on similarity, demographics, or other criteria

These components are used by all other parts of the framework (dataloaders, traversals, trainers, managers).
